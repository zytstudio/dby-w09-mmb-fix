# DBY-W09 MMB-Fix

适用于华为 Matepad 11 (2021, DBY-W09) 的鼠标中键修复 Magisk 模块。

在一些华为设备中，鼠标中键被映射为返回键和多任务键（双击）。本模块可以恢复原有的鼠标中键功能。

## 使用方法

下载 `mouse_middle_fix-v1.3.zip` ，在 Magisk / Kernel SU 或者其他 Root 管理器中刷入。

可以通过 Action 脚本动态工作状态而不用重启。

# DBY-W09 MMB-Fix

Magisk Module for Matepad 11 (2021, DBY-W09) Mouse Middle Button Fix.

On some Huawei devices, mouse middle button would be mapped as back and recent apps button (double-click). This module aims to recover the original function of mouse middle button.

## Usage

Download `mouse_middle_fix-v1.3.zip`, then flash it in your root manager such as Magisk or Kernel SU.

The working status can be changed dynamically without rebooting by running action script.
